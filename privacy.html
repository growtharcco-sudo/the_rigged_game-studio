Privacy Policy: The Rigged Game Studio

Last updated: 13 November 2026

The Rigged Game Studio is a private tool used only by the owner of The Rigged Game to publish its own videos to its own YouTube channel and Instagram account. It has no other users.

YouTube API Services

The Rigged Game Studio uses YouTube API Services to upload videos. By using it, you agree to be bound by the YouTube Terms of Service. Google's handling of data is described in the Google Privacy Policy.

What data we access, use and store

  • We use the YouTube upload permission to upload the owner's own videos to the owner's own channel, set their thumbnails, and delete the tool's own test uploads.
  • We do not read, collect, store or share any YouTube user data, channel data or analytics.
  • The only credential is the owner's OAuth refresh token, stored encrypted in the owner's GitHub Actions secrets. It is never shared or sold.
  • No cookies, tracking or advertising are used.

Revoking access and deletion

Access can be revoked at any time at Google security settings. To delete the stored token, the owner removes it from the repository secrets; it is then deleted permanently. Because no other user data is stored, there is nothing else to delete. Contact: message @the_rigged_game on Instagram.

The Rigged Game Studio's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
