# The Rigged Game Studio

Makes Reels / Shorts for The Rigged Game (Instagram and YouTube @the_rigged_game): noir paper-cutout animation
about how casinos really work. Follow `ROUTINE.md` step by step.

Hard rules:
- Education only: never promote gambling, never name, show or link a betting site or app, no promo codes,
  no "how to win". Every caption says "Education only. Not gambling advice. 18+".
- Write a brief and run `pipeline/kit.py`; never hand-write scene coordinates. Check with ONE `--sheet` image.
- Voice is Kokoro `am_liam` at speed 1.0, one full line per beat, never spliced. No lone short lines.
- No em dashes anywhere. Instagram caption ends with exactly 5 hashtags including #theriggedgame.
- Every fact sourced the same day; arithmetic run in Python.
- Video quality: 1080x1920, H.264 High CRF 14, never re-compressed or squeezed.
